Player

Учебный проект · предварительная версия 2.2.0

Windows 11 · x64

Сугубо учебный проект на C# для изучения системного звука Windows, фоновой обработки и безопасного сохранения файлов.

Пока только исходники. Для работы нужен совместимый FFmpeg; интерфейс на русском. Не профессиональное средство записи.
