SoundLeaf

Предварительная версия 3.0.5 · Windows 11 · x64

Учебный проект записи системного звука Windows: управление в трее, резервный WAV и проверка итоговых файлов.

Windows 11 x64, .NET Framework 4.8, доступная для записи папка и устройство вывода. Автономный Setup и portable включают FFmpeg, исходники и лицензии. Без администратора.
