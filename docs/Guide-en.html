SoundLeaf

Strictly an educational C# project exploring Windows system audio, background work and durable file storage.

Preflight and WAV-only mode

Automatic capture starts only after background checks of durable folder writes, free space and a short selected-profile encode/decode. Each FFmpeg process has a three-second limit; the tray stays responsive. Below 256 MiB, capture is blocked; between 256 MiB and 1 GiB, or unknown space, a warning is shown. Unknown space requires a successful folder-write check. These initial checks cannot guarantee room for the entire session.

If the selected profile is unavailable, the reason and “Начать запись только в WAV” menu command are shown. No automatic mode switch occurs. WAV-only mode never runs the encoder. After stopping, the result lists every verified WAV, explicitly states that no MKV was created and offers a folder-opening command. Long recordings remain parts of up to 256 MiB. Atomic completion markers in State/Sessions exclude intentional WAV results from crash recovery; marker failure preserves audio but reports an error. Move State together with the recordings.

The saving icon has a fixed green triangle centered inside a thicker rotating arc: 24 frames, 80 ms per frame.

Start

Build the executable using the README commands. Place compatible FFmpeg at tools/ffmpeg.exe beside the EXE. Use a writable folder and rename the verified candidate to SoundLeaf.exe for regular use.

Recording starts automatically on launch. Only record permitted material with required consent. The source is the default Windows output device, not the microphone.

Tray controls

Left click toggles the compact panel; right click opens the fallback menu. Escape or clicking outside hides the panel without stopping capture. Pause time is excluded from output. Stop and save keeps SoundLeaf in the tray; Exit waits for saving.

Green play: recording. Yellow bars: paused. Rotating ring: processing. Black square: stopped. Red: failure or unfinished previous sessions while stopped.

Saving stages appear in the menu and tooltip. Success refers to a verified MKV or intentionally completed WAV parts, not every historical recording. The result command opens the last verified file or WAV folder.

Recovery

Stop the current session and select the unfinished-session recovery command. WAV parts are checked, encoded and combined. Originals are moved to Backups/RecoveredSessions only after full output verification, never deleted by recovery.

Missing/duplicate parts, active writers, incompatible formats and existing outputs are rejected. Failed attempts preserve originals and may retain work files. A newer successful recording does not resolve an older failed session.

Storage and limits

Recordings and logs are beside the EXE. Move the whole folder and re-enable startup after moving. Silence is normal. Start a new session after changing the output device.

Tested locally on one computer. No absolute protection from disk/power failure. Extended endurance and clean-machine deployment remain untested. Review personal audio, logs and paths before sharing.

Profiles, settings and recordings

Default: MKV / AAC 192 kbit/s with original sample rate and channels. Choose one format and bitrate while stopped: OGG/Opus starts at 24 kbit/s, mono, 48 kHz, speech VBR; MP3 uses CBR; M4A/AAC and AAC/ADTS use AAC-LC. Additional MP3/AAC use 48 kHz and up to two channels. Backup WAV preserves original PCM. Opus bitrates: 16/24/32/48/64/96/128; AAC/MP3: 64/96/128/160/192/256/320. VBR bitrate is a target, not a guaranteed file size.

Left click toggles Controls / Recordings / Settings; right click opens the fallback menu. Escape and outside clicks hide the panel without stopping capture. Language Deutsch / Русский / English and light/dark/Windows theme change immediately.

Select a save folder in Settings; older files are not moved and previously selected folders remain in the library. Custom folders keep their own State/Sessions beside dated recordings: keep metadata with audio. The library loads in the background; unknown historical durations are not invented and temporary files are excluded.

“Save in another format” creates a separate fully checked file with selected bitrate and destination; the original is preserved. Lossy re-encoding does not improve quality. Existing targets and wrong extensions are refused. Recovery uses the saved session profile, or MKV/AAC 192 for legacy sessions. One continuous encoder spans WAV boundaries for additional formats, with direct PCM rebuild on failure; WAV deletion follows successful publication.
