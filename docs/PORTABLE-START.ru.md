# Player 2.2 — локальная учебная сборка

Сугубо учебный проект для Windows x64, не профессиональное средство записи. Запускайте `Player.exe` из этой папки. Для сохранения нужен `tools/ffmpeg.exe`. Запись системного звука начинается автоматически; используйте только разрешённые материалы с необходимым согласием участников.

Щелчок по значку открывает меню. Зелёный треугольник — запись, жёлтые полоски — пауза, вращающееся кольцо — обработка, чёрный квадрат — остановка, красный знак — ошибка или незавершённые предыдущие сессии при остановке.

При остановке дождитесь завершения кодирования и проверки. В меню показаны результат и путь к проверенному файлу; его можно открыть отдельной командой. Незавершённые старые сессии считаются отдельно. Команда «Собрать незавершённые записи» доступна после остановки текущей записи; оригиналы сохраняются в `Backups/RecoveredSessions`.

Записи находятся в `Recordings`, журналы — в `logs`. Автозапуск включается в меню без прав администратора. После переноса папки его нужно выключить и снова включить.

Изменения установленного EXE вступают в силу при следующем запуске. Чтобы обновиться без прерывания записи: остановить и сохранить → дождаться проверки → выход → снова запустить EXE.

Исходный Git-проект этой установки находится в подпапке `Project`. Публичный готовый бинарный выпуск ещё не опубликован. Длительный прогон и чистая установка не проверены; абсолютной гарантии сохранности при сбое питания или диска нет.
