SoundLeaf

Сугубо учебный проект на C#: системный звук Windows, фоновая обработка и безопасное сохранение файлов.

Проверки и режим только WAV

Автоматическая запись начинается только после фоновой проверки папки, свободного места и короткого кодирования/декодирования AAC/MKV. Каждый процесс FFmpeg ограничен тремя секундами. Трей остаётся доступным. Меньше 256 МиБ — запись запрещена; от 256 МиБ до 1 ГиБ или неизвестный объём — предупреждение. Если место неизвестно, обязательна успешная проверка записи в папку. Начальная проверка не гарантирует места на всю сессию.

При недоступном профиле показана причина и предлагается «Начать запись только в WAV»; автоматического перехода нет. Кодировщик в этом режиме не запускается. После остановки показаны все проверенные WAV, сообщение «WAV сохранён; MKV не создавался» и команда открытия папки. Длинная запись остаётся частями до 256 МиБ. Успешные WAV-сессии отмечаются атомарно в State/Sessions и не считаются аварийными. Ошибка фиксации сохраняет аудио, но не считается успехом. Переносите State вместе с записями.

При сохранении зелёный треугольник неподвижен по центру более толстой вращающейся дуги: 24 кадра, по 80 мс.

Учебный проект · предварительная версия 3.0.0

Windows 11 · x64. Не профессиональное средство записи. Публичного готового бинарного выпуска пока нет. Интерфейс: Deutsch / Русский / English.

Перед запуском

Соберите EXE командой из README, положите совместимый FFmpeg в tools/ffmpeg.exe рядом с ним. Запускайте из доступной для записи папки. Для обычной работы назовите проверенный EXE SoundLeaf.exe.

Запись начинается автоматически. Записывайте только разрешённые материалы с необходимым согласием участников. Источник — системный звук устройства вывода Windows по умолчанию, не микрофон.

Управление из трея

Левый щелчок открывает панель, правый — резервное меню. Escape и щелчок снаружи скрывают панель без остановки записи. Пауза исключает своё время из записи. «Остановить и сохранить» оставляет программу в трее; «Выход» сначала завершает сохранение.

Зелёный треугольник — запись; жёлтые полоски — пауза; вращающееся кольцо — обработка; чёрный квадрат — остановка. Красный знак обозначает ошибку либо незавершённые прошлые сессии после остановки.

Этапы сохранения видны в меню и подсказке. Успех относится к конкретному проверенному MKV или намеренно завершённым WAV-частям. Команда открытия результата доступна только при наличии проверенного файла.

Если остались части записи

Остановите текущую запись и выберите «Собрать незавершённые записи». Сначала проверяются WAV-части, затем создаётся и проверяется единый MKV. Оригиналы после успеха перемещаются в Backups/RecoveredSessions, а не удаляются.

Пропущенные или дублированные части, активные писатели и существующий итоговый файл требуют ручного разбора. При неудаче исходники остаются. Старые ошибки не считаются исправленными только потому, что новая запись завершилась.

Хранение и ограничения

Записи — в Recordings рядом с EXE, журнал — в logs. Переносите всю папку; после переноса заново включите автозапуск. Тишина не ошибка. При смене устройства начните новую сессию.

Проверено локально на одном компьютере. Нет абсолютной защиты от отказа диска и питания. Многочасовой прогон и чистая установка ещё не проверены. Не публикуйте личные записи и журналы без проверки.

Профили, настройки и записи

По умолчанию MKV / AAC 192 кбит/с с исходными каналами и частотой. После остановки выберите один формат и битрейт: OGG/Opus начинается с 24 кбит/с, моно, 48 кГц, речевой VBR; MP3 — постоянный битрейт; M4A/AAC и AAC/ADTS — AAC-LC. Дополнительные MP3/AAC: 48 кГц, до двух каналов. WAV сохраняет исходный PCM. Opus: 16/24/32/48/64/96/128; AAC/MP3: 64/96/128/160/192/256/320. VBR — целевой битрейт, не гарантия размера.

Левый щелчок открывает «Управление / Записи / Настройки», правый — резервное меню. Escape и щелчок снаружи скрывают панель без остановки. Deutsch / Русский / English и светлая/тёмная/системная тема меняются сразу.

В настройках выбирается папка сохранения; старые файлы не перемещаются, прежние папки остаются в списке. Внешняя папка хранит свои State/Sessions рядом с датированными записями: переносите метаданные вместе с аудио. Список загружается в фоне; неизвестная длительность не выдумывается, временные файлы исключены.

«Пересохранить» создаёт отдельный полностью проверенный файл с выбранными битрейтом и местом; исходник остаётся. Перекодирование сжатого звука не улучшает качество. Существующий итог и неверное расширение запрещены. Восстановление использует профиль сессии, для старых без профиля — MKV/AAC 192. Дополнительные форматы кодируются непрерывно через WAV-границы; при отказе пересобираются напрямую из PCM. WAV удаляется после успешной публикации.
