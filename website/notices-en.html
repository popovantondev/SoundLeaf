Third-party components

Components included in the offline SoundLeaf 3.0.5 release.

FFmpeg and audio codecs

SoundLeaf invokes FFmpeg as a separate process; it does not link to its libraries. Offline 3.0.5 includes minimal FFmpeg 9.0.2, Opus 1.6.1 and LAME 3.100, built from unmodified upstream sources. GPL, version3 and nonfree options are disabled. FFmpeg reports LGPL 2.1 or later. Network protocols are disabled.

Corresponding source

The corresponding source kit ffmpeg-9.0.2-corresponding-source.zip is included under tools and separately available on the same release page. It contains original source archives, build script/instructions, configuration evidence and unmodified component notices. Only encoder/build-minimal.sh has an additional LGPL-2.1-or-later permission; SoundLeaf's application rights remain unchanged.
