Choose a format
for your recording

SoundLeaf’s supported formats. Change the format and save folder only while recording is stopped.

MKV AAC. Default profile: 192 kbit/s.
OGG Opus: initially 24 kbit/s, mono, 48 kHz, speech-oriented VBR.
MP3 CBR with a selectable bitrate.
M4A AAC in an M4A container.
AAC AAC / ADTS.
WAV-only Explicit mode without FFmpeg.
Saving and recovery

Recording does not end at “Stop”

After stopping, SoundLeaf checks the result before marking it complete.

WAV backup and verification

A PCM/WAV backup is maintained during recording. The final file becomes available only after encoding, verification by decoding and a duration check.

Recover unfinished sessions

SoundLeaf can detect unfinished sessions and rebuild them from verified WAV parts. Originals are archived only after successful recovery.

i

Only with every participant’s consent

Record conversations only if every participant has agreed beforehand after being informed (§ 201 German Criminal Code, GDPR). If someone refuses or withdraws consent, stop recording.
