# SoundLeaf website source

This directory is the canonical static GitHub Pages site. The Russian default homepage and DE/RU/EN homepages, guides and legal viewers share local assets and a persistent light/dark theme switch. Application screenshots match the selected language and theme.

Run `./Build-Pages.ps1` from the repository root to validate UTF-8, canonical notices and local asset links and produce a fresh preview directory. Add `-SyncRoot` to synchronize only the allowlisted static files into the GitHub Pages root. Never substitute a guide for `index.html`.

Original license texts and root rights/notices are unchanged. Website-only updates do not rebuild or replace published application releases. The existing offline release remains immutable; its bundled documentation is independent of this web presentation.
