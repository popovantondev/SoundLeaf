SoundLeaf · Условия использования

Сторонние компоненты

Компоненты, включённые в автономный выпуск SoundLeaf 3.0.5.

FFmpeg и аудиокодеки

SoundLeaf запускает FFmpeg отдельным процессом и не связывается с его библиотеками. Автономный выпуск 3.0.5 включает минимальный FFmpeg 9.0.2, Opus 1.6.1 и LAME 3.100, собранные из неизменённых исходников разработчиков. Опции GPL, version3 и nonfree отключены. FFmpeg сообщает LGPL 2.1 или более позднюю версию. Сетевые протоколы отключены.

Соответствующие исходники

Комплект соответствующих исходников ffmpeg-9.0.2-corresponding-source.zip включён в папку tools и отдельно доступен на странице того же выпуска. Он содержит оригинальные архивы исходников, скрипт и инструкции сборки, сведения о конфигурации и неизменённые уведомления о компонентах. Дополнительное разрешение LGPL-2.1-or-later относится только к encoder/build-minimal.sh; права на приложение SoundLeaf остаются без изменений.

Лицензии компонентов

См. tools/licenses: LGPL для FFmpeg, условия BSD для Opus, LGPL для LAME, условия для среды выполнения и заголовков MinGW-w64, winpthreads и среды выполнения GCC, включая Runtime Library Exception. Ограничения собственного исходного кода SoundLeaf не распространяются на компоненты с отдельными лицензиями.

Системные технологии

Используются системные .NET Framework, Windows Forms, System.Drawing и WASAPI; отдельная среда .NET не включена. Архив исходников приложения не содержит бинарного кодировщика.
